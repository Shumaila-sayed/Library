# 📚 Library/Book Tracker

A simple JavaScript project to track books in a personal library. Users can add, remove, and update book details dynamically.

## 🚀 Features

- **Add New Books**: Enter book details (title, author, pages, read status).
- **Dynamic Display**: Books are shown in a table or card format.
- **Toggle Read Status**: Update whether a book has been read.
- **Remove Books**: Delete books from the list easily.
- **Search & Filter**: Easily find books.
- **Responsive UI**: Interactive form for user input.
